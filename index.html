- Choose your options and press pack to generate a zip 100% optimized for JS13kGames (single HTML file, utf-8 BOM, minified, roadrolled, zip + zopfli)
- If you have images (or other binary files), consider compressing them and including them in base64 inside your HTML code using this tool.
- Everything is saved in localStorage so you can exit and come back later.
